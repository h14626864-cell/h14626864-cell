### 👋 About Me

I'm **Hamza Talal**, a 15-year-old full-stack developer from Egypt, currently in my first year of secondary school. I've been building for the web for over 2 years — and in that time I've designed, built and **shipped 7 complete live products**, from an Arabic e-commerce storefront to an AI-powered detective game.

I work the way product engineers work: one runtime I trust deeply (**Node.js**), a component architecture I think in (**React / Next.js**), and real databases behind everything I ship (**PostgreSQL · Prisma · Firebase · Convex**). Currently expanding into **Laravel**.

- 🌍 Based in Egypt · writing code every single day, without exception
- 🧠 Self-taught — everything I know came from building real things
- 🚀 Goal: build products people actually use
